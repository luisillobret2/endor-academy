One Security Protocol for Every Coding Agent

The old integration model — one plugin per IDE — ages badly. Every IDE release breaks a plugin, and every new coding assistant needs yet another integration to be written and maintained. Endor Labs took a different path: it exposes the platform’s security capabilities through an MCP server, so any MCP-capable client can call the same tools.

💡 What Is MCP?

The Model Context Protocol is an open standard for connecting AI applications to external tools and data sources. Instead of building a plugin for every editor, Endor Labs builds one MCP server — and Cursor, Claude Code, VS Code, Codex, Gemini CLI, and the rest all speak to it in the same way.

For developers this matters commercially as well as technically: Endor Labs’ agentic security capabilities are free for developers — “AURI for developers is free forever” — so individual engineers and entire dev teams can adopt the MCP server without a procurement cycle.

Install the Endor Labs MCP Server

Starting the server is one command — no separate binary to install and keep up to date, because npx fetches and runs it for you:

npx -y endorctl ai-tools mcp-server
  1. Check prerequisites — you need Node.js/npx available and an authenticated endorctl.
  2. Cursor users — use the one-click install from the Endor Labs integrations page, or register the server in .cursor/mcp.json as shown below.
  3. Every other client — register the same command in your client’s MCP configuration; the snippet shape is identical for Claude Code, Codex, VS Code/Copilot, Gemini CLI, and the rest.

💡 Register the Server in .cursor/mcp.json

Drop this into your repository so the whole team gets the Endor Labs tools with zero per-machine setup:

{
  "mcpServers": {
    "endor-labs": {
      "command": "npx",
      "args": ["-y", "endorctl", "ai-tools", "mcp-server"]
    }
  }
}

Supported clients include Cursor, Claude Code, OpenAI Codex, VS Code/Copilot, Gemini CLI, Augment, IntelliJ, Google Antigravity, Devin, OpenCode, and GitHub AgentHQ. One server, one command, every major agent.

What Your Agent Can Now Do

Once connected, the agent’s security skills stop being prompts and start being tools backed by the Endor Labs platform:

🐛

Find and Fix Vulnerabilities

The agent pulls findings with their call-path evidence, proposes the version upgrade or code fix, and — because it sees reachability — works the findings that matter instead of chasing unreachable noise.

🔑

Detect Secrets Before Commit

Agents routinely paste example keys and tokens into code. Endor Labs secrets detection flags credentials before they are committed — with the same rules from laptop to pipeline.

🛡

Block Malicious Packages

Before the agent installs a package, Endor Labs checks it against malicious-package intelligence — typosquatting, dependency confusion, and compromised releases — with the Package Firewall enforcing policy at install time.

📊

Answer With Evidence

“Is this library safe to add?” The agent answers with Endor Scores — activity, popularity, security, and code quality — instead of guessing from a README.

Everything happens in your editor’s normal flow: the agent proposes a diff, you review it, you accept it. The agent does the legwork; you stay in control.

Agent Kit and Safe Autonomy

The Endor Labs Agent Kit packages pre-built agent workflows for Claude Code, Cursor, OpenAI Codex, Gemini CLI, Google Antigravity CLI, and the Cursor SDK. The workflows are portable — defined once and run in different environments — so a team can version, review, and share agent workflows exactly like code.

The safety model is what makes autonomy acceptable: Agent Kit actions are approval-gated and read-only by default. Agents propose changes rather than silently making them, risky actions pause for a human, and every action is logged. The full governance story — inventories, policies, and audit trails — is covered in the Secure AI Coding & Agent Governance module.

⚠️ Important for Partners

Developers are already asking agents to write code — the only question is whether security rides along or gets bolted on later. The MCP server (free for developers) plus an Agent Kit demo is the strongest developer-land opening Endor Labs has, and it sets up the governance conversation that follows.
